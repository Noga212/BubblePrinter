BubblePrinter: This is website for assisting with planning a "print" by inflating plastic bubbles. This project was made in an academic environment for a grade, for a hypothetical printer.

The software includes the following features:
1. Transforming an obj file (either uploaded by the user or on a built-in test obj) to bubbles.
2. Controlling the size, distribution, and arrangement of the bubbles.
3. Controlling the viewpoint and graphics (like light, shadow, etc.).
4. Slicing by layers or by bubbles.
5. Downloading the file and a simple G-code (x, y, z of center or top, and radius).

The software should be very intuitive. By hovering with the mouse over buttons, you can get a description of what each does.
